# ⚡ PySpark Data Processing

Big Data project focused on distributed data processing with **Apache Spark and PySpark**.

The project explores Spark from different perspectives: low-level processing with **RDDs**, structured analysis with **Spark SQL and DataFrames**, and storage/performance optimization using **Parquet**.

Developed as part of my MSc in Big Data & Artificial Intelligence.

## 📌 Project Overview

This project is divided into three practical tasks covering different components of the Apache Spark ecosystem.

The main objectives are:

- Working with distributed datasets using PySpark
- Applying transformations and actions with RDDs
- Performing statistical calculations
- Processing structured data with Spark DataFrames
- Using Spark SQL for data analysis
- Aggregating and joining large datasets
- Working with real sensor data
- Comparing CSV and Parquet storage formats
- Analyzing processing performance

## 1️⃣ RDDs & Statistical Analysis

The first task focuses on the fundamentals of distributed processing using **Resilient Distributed Datasets (RDDs)**.

The workflow includes:

- Loading data into Spark
- Cleaning incorrect values
- Filtering observations
- Transforming data with `map`
- Using `filter`, `reduce`
